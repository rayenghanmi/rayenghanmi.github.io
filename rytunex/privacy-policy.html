Privacy Policy

Last updated: October 2026

This page reflects the official RyTuneX privacy policy for our Windows and Android applications. Your privacy is not a feature, it's the foundation.

block

Zero Data Collection

No personal data, telemetry, analytics, or device identifiers collected on any platform.

storage

Local-Only Storage

Settings remain strictly local on your device and are never synced to any remote server.

wifi_off

Stateless & Offline

Offline by default. Android runs statelessly via Shizuku with zero background battery drain.

I built RyTuneX for Windows and Android as open-source tools with a simple philosophy: your data is none of my business. This privacy policy explains how both applications handle information, or rather, how they don't. The code for both editions is fully open-source on GitHub, so you can inspect and verify every single line yourself.

Section 01

block No Data Collection

Personal Information: I do not collect, store, transmit, or have access to any of your personal information across any platform. This includes names, email addresses, IP addresses, phone numbers, IMEI, hardware identifiers, Android ID, or any other identifying data.

Usage Tracking: Neither RyTuneX for Windows nor RyTuneX for Android contains any telemetry, analytics, crash trackers, or user profiling tools. I have no way of knowing how you use the apps, which packages you debloat, or which tweaks you apply.

Location & Sensor Data: RyTuneX never accesses or tracks your location, camera, microphone, contacts, or personal files.

Section 02

storage Local Storage & Stateless Architecture

Any settings, configurations, or profiles configured within RyTuneX remain exclusively on your local device:

Windows: Stored locally in your user profile using Windows application storage APIs. Never synced to any cloud service.

Android: Stored locally inside the app's sandboxed storage (`SharedPreferences` / DataStore). Universal Android Debloater (UAD-NG) definitions are bundled directly offline within the APK.

Stateless Shizuku Execution: RyTuneX for Android operates via Shizuku (ADB UID 2000). It does not install any permanent background daemons, persistent root services, or resident background workers, ensuring zero battery consumption and zero persistent surveillance.

If you uninstall either application, all local configuration files are deleted immediately by the OS.

Section 03

wifi Internet Connectivity & DNS

RyTuneX is designed from the ground up to operate completely offline. It only connects to the internet if you explicitly trigger a network-dependent action:

Update Checks: When manually checking for updates, the app queries the public GitHub Releases API. No personal data is transmitted; requests contain only standard HTTP client headers.

Encrypted DNS (DoT) on Android: When applying an Encrypted DNS preset (e.g., Cloudflare, AdGuard, Quad9, Google), RyTuneX sets the operating system's native Private DNS host configuration. RyTuneX does not proxy, inspect, or log your internet or DNS traffic — resolution occurs directly between your Android device and your chosen DNS provider.

Section 04

open_in_new Third-Party Services & Integrations

This website uses a single third-party widget: Buy Me a Coffee (buymeacoffee.com), which loads a voluntary support button in the bottom corner of the site. It is governed by Buy Me a Coffee's privacy policy and may set a browser cookie or log IP addresses when loaded.

Application Integrity: Neither the Windows application nor the Android application contains third-party advertising SDKs, tracking libraries, or proprietary surveillance code. Third-party integrations are purely open-source tooling:

• WinGet: Microsoft's package manager on Windows, invoked strictly when you request software management.

• Shizuku: An open-source interface by the Shizuku project used solely for authorized user-level ADB IPC.

• UAD-NG: Community-maintained package definitions from the Universal Debloater Alliance, stored locally offline.

Section 05

update Changes to This Policy

If any future release of RyTuneX incorporates an optional capability that interacts with external networks (such as opt-in crash diagnostics), this policy will be updated with full disclosure, and such features will always remain strictly opt-in.

The current policy across all platforms reflects: RyTuneX collects zero personal data.

Section 06

contact_support Contact & Open Source Repositories

Because RyTuneX is 100% open-source under AGPL-3.0, you can audit the source code for both platforms:

• Windows: github.com/rayenghanmi/RyTuneX

• Android: github.com/rayenghanmi/RyTuneX-Android

For any questions, open an issue on either GitHub repository or email rytunex@gmail.com.
