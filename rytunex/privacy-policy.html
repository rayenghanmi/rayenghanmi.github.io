Privacy Policy

Last updated: September 2026

This page reflects the official RyTuneX privacy policy published for the Microsoft Store listing. Your privacy is not a feature, it's the foundation.

block

Zero Data Collection

No personal data, analytics, or telemetry of any kind is collected.

storage

Local-Only Storage

All settings remain on your machine and are never synced to any server.

wifi_off

Offline by Design

Internet access is strictly optional and only used for update checks.

I built RyTuneX as an open-source tool with a simple philosophy: your data is none of my business. This privacy policy explains how I handle information, or rather, how I don't. The code is fully open-source on GitHub, so you can verify every word here yourself.

Section 01

block No Data Collection

Personal Information: I do not collect, store, or have access to any of your personal information. This includes your name, email address, IP address, hardware identifiers, or any other identifying data.

Usage Tracking: I do not use any analytics or telemetry tools. I have no way of knowing how you use the app, how many times you open it, or which features you toggle.

Location: RyTuneX does not access or track your location at any time.

Section 02

storage Local Storage Only

Any settings or preferences you configure within the app are stored locally on your computer only, using Windows application storage APIs. This data is never uploaded to a server, never synced to any cloud service, and never accessible by anyone other than you.

If you uninstall the app, this local data is removed along with it.

Section 03

wifi Internet Connectivity

RyTuneX is designed and optimized to work completely offline. It only connects to the internet if you manually trigger an update check from within the app.

When checking for updates, the app sends a single request to the public RyTuneX GitHub repository to fetch the latest version tag. No personal data is transmitted during this process, the request contains only the standard HTTP headers.

Section 04

open_in_new Third-Party Services

This website uses a single third-party widget: Buy Me a Coffee (buymeacoffee.com), which loads a small support button in the bottom corner of the page. This widget is provided by Buy Me a Coffee, Inc. and is subject to their own privacy policy. It may set a browser cookie and may log your IP address when the widget script loads.

The RyTuneX desktop application itself has no third-party SDKs, advertisements, analytics, or data-sharing of any kind. The widget is present only on this website and only to allow voluntary financial support. No personal data from the app is ever shared with anyone.

Section 05

update Changes to This Policy

If a future version of RyTuneX introduces a feature that requires data handling (such as optional crash reporting), I will update this policy, clearly describe what changed, and ensure it remains opt-in.

The current version of this policy reflects that RyTuneX collects nothing.

Section 06

contact_support Contact & Open Source

Since RyTuneX is fully open-source, you can inspect every line of code yourself on GitHub. If you have any questions about this policy or concerns about behavior you observe, please open an issue on github.com/rayenghanmi/rytunex.

Alternatively, reach me at rytunex@gmail.com.
