Everything it can change. All of it reversible.

Hardware-aware tuning

Scores your system health and suggests presets that fit your hardware.

Package control

Remove or manage built-in Windows components and hidden telemetry modules.

Network and latency

Set DNS, trace DPC latency overhead and block unwanted outbound connections.

Software with WinGet

Search, install and update apps from inside RyTuneX.

Shareable profiles

Export a gaming or workstation setup as .json and import it on another PC.

Rollback and logs

Undo any item on its own. Read every action in the built-in log viewer. AGPL-3.0, so you can read the source too.

The same engine for your phone.

Tune the display, cut touch latency, remove preinstalled apps and set system-wide encrypted DNS. No root, no background services, no battery drain.

  • Runs on Android 8.0+ through Shizuku and Wireless Debugging.
  • One-tap profiles: Extreme Gaming, Adaptive Endurance, RyTuneX Fluid, Reset to Stock.
  • Asks before every system change and rolls back all of them in one tap.
  • DNS-over-TLS with Cloudflare, AdGuard, Quad9, Google or your own server.
